MongoDB Search: the conventional entry, and the same search on Cilium Cluster Mesh

Conventionally, each cluster's search is reached through a chain of hops in which the router, the Route and Envoy all match one hostname, and Envoy accepts exactly that one name. On Cluster Mesh, every mongod dials one global Service name, and the network sends a cluster's searches elsewhere when its mongot are gone.
