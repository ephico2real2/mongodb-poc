mongodb-poc · vanity hostname · issue #198 · proposed

A vanity hostname through a second Envoy, to the same mongot pods

The operator's Envoy accepts one TLS server name, externalHostname, and the operator reconciles it, so it cannot be given a second one. The proposed chart mongot-envoy-vanity-url-helm runs a second Envoy whose only filter chain accepts the vanity name, behind its own passthrough Route, and sends to the same mongot pods with the same secrets.

Two entry paths, one set of mongot pods
