Shared services on Cilium Cluster Mesh, and a copy for disaster recovery

The observability services run in one cluster and every cluster reaches them by name, through Cilium global Services. A global Service load-balances each connection to one backend; it does not copy. A second copy therefore comes from the writers, which send every record to both.
